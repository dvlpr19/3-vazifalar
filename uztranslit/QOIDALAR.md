# Arab yozuvidan o'zbek lotin yozuviga o'girish qoidalari

`arab_lotin()` funksiyasi shu qoidalar asosida ishlaydi. O'zbek diniy adabiyotida keng tarqalgan
yozilishga tayanildi: cho'ziq "ā" → **o** (Islom, Qurʼon, Rahmon), cho'ziq "ī" → **i**, "ū" → **u**.

Arab yozuvida bosh harf yo'q, shuning uchun natija kichik harflarda chiqadi.
Yagona istisno — **Alloh** (الله) so'zi doim bosh harf bilan yoziladi.

## 1. O'zbek tilida aniq mosi yo'q harflar

| Harf | Nomi | Lotin | Misol |
|---|---|---|---|
| ع | ayn | **ʼ** (tutuq belgisi); so'z boshida yozilmaydi | مَعْنَى → maʼno, سَعْد → saʼd, عُمَر → umar |
| ح | ha (bo'g'iz "h") | **h** | حَسَن → hasan, مُحَمَّد → muhammad |
| ق | qof | **q** | قُرْآن → qurʼon |
| غ | g'ayn | **gʻ** | غَفُور → gʻafur |
| خ | xo | **x** | خَالِد → xolid |

ح va ه ikkalasi ham **h** bo'ladi. O'zbek yozuvida ular farqlanmaydi.

## 2. Boshqa undoshlar

| Harf | Lotin | Izoh / misol |
|---|---|---|
| ب ت ج د ر ز س ف ك ل م ن ه | b t j d r z s f k l m n h | |
| ش | sh | شُكْرًا → shukran |
| ث | s | ثَابِت → sobit |
| ذ ز ض ظ | z | ذِكْر → zikr, رَمَضَان → ramazon, ظُهْر → zuhr |
| ص | s | صَبْر → sabr |
| ط | t | طَالِب → tolib |
| و | v (undosh bo'lganda) | وَلِيّ → valiy, يَوْم → yavm |
| ي | y (undosh bo'lganda) | يُوسُف → yusuf, حُسَيْن → husayn |
| ء أ إ ؤ ئ | **ʼ** (hamza); so'z boshida yozilmaydi | أَحْمَد → ahmad, رَأْس → raʼs, شَاءَ → shoʼa |

Fors harflari (ک, ی) arabcha ك, ي kabi o'qiladi.

## 3. Harakatlar (qisqa unlilar)

| Belgi | Nomi | Lotin | Misol |
|---|---|---|---|
| ـَ | fatha | a | حَسَن → hasan |
| ـِ | kasra | i | ذِكْر → zikr |
| ـُ | damma | u | عُمَر → umar |
| ـْ | sukun | — (unli yo'q) | سَعْد → saʼd |
| ـّ | shadda | undosh ikkilanadi | مُحَمَّد → muhammad, مَكَّة → makka |
| ـً ـٍ ـٌ | tanvin | an, in, un | شُكْرًا → shukran |

So'z oxiridagi shadda ikkilanmaydi: عَلِيّ → aliy, حَقّ → haq.

## 4. Cho'ziq unlilar

| Yozilishi | Lotin | Misol |
|---|---|---|
| ـَا (fatha + alif) | **o** | كِتَاب → kitob, سَلَام → salom |
| ـٰ (kichik alif) | **o** | الرَّحْمٰن → ar-rahmon |
| ـَى (alif maqsura) | **o** | مُوسَى → muso, مَعْنَى → maʼno |
| آ (alif madda) | **o**; so'z o'rtasida **ʼo** | آدَم → odam, قُرْآن → qurʼon |
| ـُو (damma + vov) | **u** | غَفُور → gʻafur, يُوسُف → yusuf |
| ـِي (kasra + yo) | **i** | رَحِيم → rahim, كَرِيم → karim |
| ـَيْ / ـَوْ (diftong) | ay / av | حُسَيْن → husayn, يَوْم → yavm |

Harakatsiz matnda ا → o, و → u, ي → i deb o'qiladi (so'z boshida va harakatli bo'lsa — v, y undoshi).

## 5. "al-" artikli

| Holat | Qoida | Misol |
|---|---|---|
| Qamariy harflar (ا ب ج ح خ ع غ ف ق ك م ه و ي) | **al-** | الْقَمَر → al-qamar, الْكِتَاب → al-kitob |
| Shamsiy (quyosh) harflar (ت ث د ذ ر ز س ش ص ض ط ظ ل ن) | "l" keyingi harfga aylanadi: **a** + harf + **-** | الشَّمْس → ash-shams, الرَّحْمٰن → ar-rahmon, السَّلَام → as-salom |

Shamsiy harf ustidagi shadda artikl hisobiga yoziladi, qayta ikkilanmaydi (ash-shams, ash-shshams emas).

## 6. Ta marbuta (ة)

| Holat | Lotin | Misol |
|---|---|---|
| So'z oxirida, harakatsiz (to'xtab o'qish — vaqf) | **a** | فَاطِمَة → fotima, مَكَّة → makka |
| Harakati bor (izofa, kelishik qo'shimchasi) | **t** + unli | رَحْمَةُ → rahmatu |

## 7. Maxsus so'zlar va belgilar

| Arabcha | Lotin |
|---|---|
| الله, اللّٰه | Alloh |
| و (alohida turgan bog'lovchi) | va |
| ، ؛ ؟ | , ; ? |
| ٠١٢٣٤٥٦٧٨٩ | 0123456789 |

Arab bo'lmagan matn (lotin, kirill, raqamlar) o'zgarmaydi.

## Cheklovlar

- **Harakatsiz matn.** Arab yozuvida qisqa unlilar yozilmaydi, shuning uchun harakatsiz so'zni to'g'ri o'qib
  bo'lmaydi: محمد → mhmd. To'g'ri natija uchun matn harakatli bo'lishi kerak (مُحَمَّد → muhammad).
- **Vasl (so'zlarni qo'shib o'qish)** hisobga olinmaydi: بِسْمِ اللّٰهِ → "bismi Alloh" (bismillah emas),
  عَبْدُ اللّٰه → "abdu Alloh" (Abdulloh emas). Har bir so'z alohida o'giriladi.
- **Old qo'shimchalar** (وَ, بِ, لِ, فَ) so'zga qo'shib yozilganda artikl aniqlanmaydi: وَالشَّمْس.
- Ism va atamalarning o'zbek tilida o'rnashib qolgan shakllari (Abdulloh, Ramazon hayiti, shariat)
  ba'zan qoidadan farq qiladi: شَرِيعَة → shariʼa (an'anaviy yozilishi — shariat).
